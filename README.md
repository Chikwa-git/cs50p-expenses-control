# Expenses Control (CS50P Final Project)

A command-line application to track expenses, analyze price variation,
and generate monthly summaries.

This project was developed as the final assignment for Harvard's CS50P.

---

## 💡 Motivation

Financial education and inflation are major challenges in many countries.
This project aims to help users understand how prices evolve over time
and how inflation impacts everyday expenses.

---

## ⚙️ Features

- Add expenses with date, name, and value
- Track price variation of a specific expense over time
- View monthly expense summaries
- CSV-based data storage (easy export to Excel/Sheets)

---

## 🧠 Technical Highlights

- Robust input validation and error handling
- Modular function design
- Sequential price variation analysis
- Automated testing with pytest and monkeypatch

---

## 🧪 Testing

This project includes automated tests using pytest.
Interactive input was tested using monkeypatch to simulate user input,
ensuring validation logic works correctly under multiple edge cases.

---

## 📚 Concepts Applied

- File I/O with CSV
- Exception handling
- Datetime manipulation
- Unit testing
